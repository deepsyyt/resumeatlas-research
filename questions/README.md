# Questions we investigate

This directory records the questions people actually ask about resumes, ATS
systems and resume-job matching — and maps each cluster to the research that
answers it, or marks it as open.

It exists because research should start from real confusion rather than from a
keyword list.

## How these questions are collected

Recurring questions are gathered from public search data (search suggestions,
"People also ask", related searches) and from themes that recur in public career
communities. They are then **clustered into topics and synthesised**.

Two rules govern this directory:

**We do not republish anyone's words.** No post, comment or question is
reproduced verbatim from any community. What is recorded here is the *theme* —
"people repeatedly ask whether an ATS rejects resumes automatically" — not a
quotation, an author, or a link to an individual's post.

**We do not create a page per question.** This is not a Q&A index, and no study
is written simply because a question exists. Questions are an input that tells us
*what is worth measuring*. A cluster earns a study only when we hold data that
can answer it, and the study is published as a measurement — with its sample,
method and limitations — not as an answer post.

Where we have no data, the cluster says so and stays open. That is the honest
state of most of them.

## What the clusters have in common

The strongest finding from this exercise was not any individual question. It was
that a small number of **unsourced or very old statistics** govern the entire
topic space, and are recycled until search engines return them as fact.

Those statistics are tracked separately, with their provenance, in
[`sources/`](../sources/).
